Try the source feed directly

This read-only example uses the upstream public catalog, so you can test the data shape without an API key or Vyonetix account.

curl -fsSL https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json \
  | jq '{catalogVersion, dateReleased, count, vulnerabilities: [.vulnerabilities[:3][] | {cveID, vendorProject, product, dateAdded, dueDate, knownRansomwareCampaignUse}]}'

What the API provides

Developer Risk Signals provides three source-linked lookups: filter KEV catalog records, check caller-supplied package versions against OSV, and match exact OpenSSF malicious-package reports. The public sample demonstrates the CISA KEV source shape only; it is not a live API result.

Current access: the RapidAPI listing is public. Because its free plan is combined with paid tiers, RapidAPI requires a payment card even for Basic. This sample page does not provide API credentials. A no-match is not a security verdict, and the service does not assess reachability or exploitability.

Open the public API listing. Follow product updates on Telegram. Source code and the JSON fixture are available in the VYONETIX SOLUTIONS GitHub repository.

Try it from GitHub Actions

An early-access CycloneDX integration sends up to 50 supported package/version tuples to the API and writes aggregate match counts to the job summary. It uses a RapidAPI consumer key stored as a GitHub repository secret; it never includes the key in the workflow file.

  • Read the GitHub Action guide and example workflow.
  • Package names and versions are sent to RapidAPI and OSV. Do not use with confidential or private package inventories.
  • The integration's local parser check passed; an independent consumer CI run has not been verified.
